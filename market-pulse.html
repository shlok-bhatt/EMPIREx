Market Pulse

Three hidden selectors — A, B and C — choose which Customer scoring profile applies in a round.

Profile A

Activates Customer scoring profile A for the round.

Profile B

Activates Customer scoring profile B for the round.

Profile C

Activates Customer scoring profile C for the round.

When is it revealed?

Shuffle A, B and C and draw one face down before players choose. Reveal all Actions first. Then reveal the Pulse and use the matching Customer profile in the Player Reference. After scoring, return all three Pulse cards and shuffle them.
