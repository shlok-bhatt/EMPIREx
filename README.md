# EMPIREx — Enterprise Card Game Website

Responsive static website for the EMPIREx physical enterprise card game.

## Pages
- Home: product overview, learning value, story and pricing
- How to Play: seven-round gameplay and scoring guide
- Cards: complete supplied card-sheet showcase and six category links
- Individual category explanations: Customer, Action, Event, Ability, Secret Goal and Business
- Market Pulse: A/B/C profile selection
- For Schools: supplementary classroom use and institutional enquiries
- Our Story: origin and team
- FAQs, Contact, Privacy and Terms

## Main product image
`assets/empirex-card-sheet-enhanced.webp` is the supplied complete card-sheet screenshot with restrained image sharpening. It has not been redrawn, cropped or redesigned. The site shows this one image for the card showcase rather than substitute card illustrations.

## Run locally
Open `index.html` in a modern browser. No build step or package installation is required.

## Publish with GitHub Pages
1. Open repository Settings → Pages.
2. Select Deploy from a branch.
3. Choose the main branch and /(root), then save.
4. Use the published URL shown in Pages settings after deployment completes.

Committing the source does not itself enable GitHub Pages.

## Project notes
- The site is an information and enquiry showcase; no online checkout or payment is enabled.
- Individual pricing displayed: ₹599 MRP and ₹549 introductory selling price; ask the team to confirm availability.
- The 73.6% survey statistic is from the project's own 87 respondents and is not a representative national estimate.
- Institutional pricing is not represented as a confirmed offer.
- No Cambridge International endorsement or affiliation is claimed.


## Supplied card sheet
The image is enhanced with mild sharpening and assembled in the browser from small text parts under `assets/card-sheet-parts/`. This avoids binary upload size limits while preserving the complete screenshot and card designs. The browser creates a temporary AVIF image URL after all parts load.
