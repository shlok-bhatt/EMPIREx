# EMPIREx — Investor Showcase Website

A responsive static website for the EMPIREx physical enterprise card game.

## Website files
- `index.html` — homepage and product showcase
- `styles.css` — responsive visual system and layouts
- `script.js` — accessible mobile navigation and current-year footer
- `favicon.svg` — brown-and-gold brand icon
- `assets/empirex-card-back.webp` — actual card-back artwork supplied by the team
- `assets/customer-senior-citizens.webp` — actual Customer card example
- `assets/business-fashion.webp` — actual Business card example
- `privacy.html` and `terms.html` — basic website information pages

## Preview locally
Open `index.html` in a modern browser. Assets are stored locally in this repository; no build step or package installation is required.

## Publish with GitHub Pages
1. Open the repository's **Settings**.
2. Open **Pages**.
3. Under build and deployment, select **Deploy from a branch**.
4. Choose the `main` branch and the `/(root)` folder, then save.
5. Use the URL shown in the Pages settings after GitHub finishes publishing.

Publishing availability depends on the repository's GitHub plan and Pages settings. Committing the website source does not itself enable hosting.

## Project notes
- This is an investor and information showcase, not a checkout-enabled online store.
- It intentionally includes no payment processing, order form or delivery promise.
- The ₹599 MRP and ₹549 introductory selling price are the figures supplied by the project team.
- Institutional rates are labelled as proposed, not confirmed.
- The initial survey statistic is identified as an internal project survey of 87 respondents.
- Game explanations are limited to the card categories and Quick Rules visible in the supplied product reference.
- No Cambridge International endorsement or affiliation is claimed.

Confirm final product specifications and printed rules, taxes, stock, fulfilment, returns, customer support, privacy requirements and commercial terms before enabling transactions.
